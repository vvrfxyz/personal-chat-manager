# Personal Chat Manager

Personal Chat Manager is a lightweight static prototype project for a personal communication and productivity tool. It currently presents a user-facing Telegram summary workspace for reviewing key chat signals, automation cadence, and AI-generated reports.

## Live Demo

Configure GitHub Pages for your fork or deployment target.

## Project Description

Personal Chat Manager is a personal communication and productivity tool for organizing chats, reviewing conversation history, and improving message workflow efficiency.

## Included

- A polished single-page prototype built with plain HTML, CSS, and JavaScript
- A user-facing dashboard for browsing chats, report flow, and automation status
- A project description suitable for GitHub and Telegram API application forms
- MVP planning docs for product scope and database design

## Planning Docs

- `docs/mvp-prd.md`: MVP scope, user flows, page inventory, permissions, and open questions
- `docs/schema.sql`: PostgreSQL-oriented schema draft for users, Telegram accounts, chats, bindings, cursors, runs, and reports

## Run Locally

Run the frontend dev server:

```bash
npm install
npm run dev
```

Run the backend separately from `backend/`.
